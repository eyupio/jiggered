A self-hosted energy and symptom tracker

Jiggered is one Go binary with SQLite, shipped as a single container. There is no separate database service, no frontend build step and no third-party analytics, so your health log stays on a machine you choose.

What running it involves

  • One container image on GitHub Container Registry, run with Docker Compose.
  • A single SQLite database, with an automatic snapshot before upgrades.
  • An HTTPS reverse proxy in front of it.
  • Several accounts, each with its own records, and an admin to manage them.
  • Optional email for verified registration and recovery, and scheduled encrypted backups to S3-compatible storage.

What to know first

Server operators can read the database and backups in plain text. This is not end-to-end encryption. That is the trade you make for running it yourself: you control who that is. The privacy page sets out who can see what.

The application is MIT licensed. The setup instructions, configuration tables and container tags are in the repository (opens in a new tab). Hosting costs and upkeep are yours, as the pricing page notes.

Not self-hosting? The offline guide and export guide cover keeping your own copies either way.
