What you can record

Daily check-ins and personal activity points, symptom episodes, and history views are part of the app. Your account also includes CSV exports, a printable summary, JSON data tools and account deletion. Read the getting-started guide to see the workflow.

Who runs the instance matters

Each account has its own log, but server operators can access the database and backups. Use an instance and administrator you trust. This page does not promise a support response time, uptime guarantee or a particular operator's retention policy. Read the data-access and privacy explanation and ask your operator about their practices.

Public source release: planned

A public source release is planned for people who want to run their own instance. Public licensing and installation access have not been announced here. We are not presenting a private repository as an available open-source download.

Existing operators may have hosting or infrastructure costs. “Free to use” does not mean that running a server is free.
